# Wireframe: Order Records

## ภาพรวมหน้าจอ

หน้าจอแบ่งเป็น 2 คอลัมน์หลัก:
- **ซ้าย (กว้าง):** ตารางประวัติคำสั่งซื้อ (Order history)
- **ขวา (แคบ):** ฟอร์มบันทึกคำสั่งซื้อใหม่ (Record new order)

## รายละเอียดองค์ประกอบ

### Header
| องค์ประกอบ | รายละเอียด |
|---|---|
| Title | "Order Records" + badge สถานะ `LIVE` (สีเขียว) |
| Alerts | ไอคอนกระดิ่งมุมขวาบน พร้อม badge ตัวเลขแจ้งเตือน (3) |

### ตาราง Order History (คอลัมน์ซ้าย)
| คอลัมน์ | เนื้อหา |
|---|---|
| ORDER | เลขที่ออเดอร์ + วันที่/เวลา |
| CHANNEL | badge ช่องทาง: LINE / FB / POS |
| CUSTOMER | ชื่อลูกค้า + เบอร์โทร |
| TOTAL | ยอดรวม (฿) ตัวหนา |
| STATUS | badge สี: เหลือง = Awaiting payment, ฟ้า = Paid, เขียว = Completed, แดง = Cancelled |
| ACTIONS | ลิงก์ "View" |

หัวตารางมีจำนวนรายการทั้งหมด (เช่น "5 records") อยู่มุมขวาบนของ panel

### ฟอร์ม Record New Order (คอลัมน์ขวา)
1. **Channel selector** — ปุ่ม toggle 3 ตัว (LINE / FACEBOOK / STOREFRONT) เลือกได้ 1 ตัว
2. **ข้อมูลผู้รับ** — input ชื่อผู้รับ, เบอร์โทรศัพท์
3. **ที่อยู่จัดส่ง** — การ์ดที่อยู่ พร้อม radio เลือกที่อยู่หลัก, checkbox "ใช้ที่อยู่เดียวกับทะเบียนบ้าน", ฟิลด์ 6 ช่อง (บ้านเลขที่, ถนน, ตำบล, อำเภอ, จังหวัด, รหัสไปรษณีย์), ลิงก์ "+ เพิ่มที่อยู่"
4. **รายการสินค้า** — dropdown เลือกสินค้า (พร้อมจำนวนคงเหลือ), ช่องจำนวน, ปุ่มลบ (x), ลิงก์ "+ เพิ่มรายการ"
5. **สรุปยอดรวม** — แสดงยอดรวมชิดขวา
6. **Payment method** — ปุ่ม toggle (BANK TRANSFER / CASH ON DELIVERY), checkbox "Mark as already paid"
7. **CTA หลัก** — ปุ่มเต็มความกว้าง สีเข้ม "Save order & deduct stock"

### Floating Toolbar (ล่างกลางจอ)
ไอคอนลอย 4 ปุ่ม: รีเฟรช/แชร์, ข้อความ (T), แก้ไข (ดินสอ), แชท

## โครงสร้าง Layout (สัดส่วน)

- Grid 2 คอลัมน์: ซ้าย ~65% / ขวา ~35%
- แต่ละ panel เป็นการ์ดขอบมน มี shadow เบา บน background สีเทาอ่อน
- ตารางซ้าย: แถวแบ่งด้วยเส้น divider บาง, badge สถานะเป็น pill รูปแบบ rounded-full
- ฟอร์มขวา: จัดกลุ่มฟิลด์เป็น section คั่นด้วย label หัวข้อสีเทา ตัวพิมพ์เล็ก ตัวหนา
