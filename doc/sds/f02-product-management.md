# F-02: การจัดการสินค้า (Product Management)

## 1. คำอธิบายฟีเจอร์ (Feature Description)
ระบบสำหรับเพิ่ม แก้ไข ลบ ข้อมูลสินค้า อะไหล่รถจักรยานยนต์ น้ำมันเครื่อง ยาง และกำหนดรายละเอียดเบื้องต้น

## 2. กลุ่มผู้ใช้งาน (Target Users)
* ผู้ดูแลระบบ (Admin)

## 3. ความต้องการทางฟังก์ชัน (Functional Requirements)
* **FR-2.1:** Admin สามารถเพิ่มสินค้าใหม่ โดยกรอกชื่อสินค้า, SKU, บาร์โค้ดสินค้า, ราคา, ยี่ห้อ, ประเภทอะไหล่, รุ่นรถที่รองรับ, แนบรูปภาพ (อัปโหลดและเก็บใน Supabase Storage), กำหนดจำนวนคงเหลือเริ่มต้น, กำหนดจำนวนขั้นต่ำสำหรับแจ้งเตือนสินค้าเหลือน้อย, และกำหนดสถานะการเปิดจำหน่ายสินค้า
* **FR-2.2:** Admin สามารถแก้ไขข้อมูลสินค้าที่มีอยู่ให้เป็นปัจจุบันได้ (โดยสามารถเลือกสินค้าจากเงื่อนไขการกรองค้นหาอย่างน้อย 1 เงื่อนไข)
* **FR-2.3:** Admin สามารถลบสินค้าออกจากระบบ โดยต้องมีการยืนยันก่อนลบ (สามารถเลือกรายการสินค้าที่ต้องการลบได้อย่างน้อย 1 รายการ)
* **FR-2.4:** Admin สามารถค้นหาหรือเลือกดูรายการสินค้าได้

## 4. กฎทางธุรกิจ (Business Rules)
* ข้อมูลสำคัญ เช่น ชื่อสินค้าและราคา ต้องไม่เป็นค่าว่าง

## 5. ข้อมูลที่เกี่ยวข้อง (Data Requirements)
* ชื่อสินค้า, SKU, บาร์โค้ด, ราคา, ยี่ห้อ, ประเภทอะไหล่, รุ่นรถที่รองรับ, รูปภาพสินค้า, หมวดหมู่สินค้า, จำนวนคงเหลือ, เกณฑ์เตือนสต็อกต่ำ, สถานะการจำหน่าย

## 6. ส่วนติดต่อผู้ใช้งาน (User Interface)
* **หน้าจัดการสินค้า:** ตารางรายการสินค้า, ปุ่มเพิ่ม/แก้ไข/ลบ และฟอร์มสำหรับกรอกข้อมูลสินค้า
