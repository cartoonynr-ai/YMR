# F-06: ประวัติและยกเลิกคำสั่งซื้อ (Order History & Cancel)

## 1. คำอธิบายฟีเจอร์ (Feature Description)
ระบบสำหรับตรวจสอบรายการคำสั่งซื้อย้อนหลัง และรองรับการยกเลิกคำสั่งซื้อเพื่อคืนสต็อกสินค้า

## 2. กลุ่มผู้ใช้งาน (Target Users)
* ผู้ดูแลระบบ (Admin)

## 3. ความต้องการทางฟังก์ชัน (Functional Requirements)
* **FR-6.1:** แสดงรายการคำสั่งซื้อทั้งหมดในรูปแบบตาราง
* **FR-6.2:** สามารถกดดูรายละเอียดออเดอร์ (Pop-up) แสดงรายการสินค้า ราคา วิธีชำระเงิน และข้อมูลลูกค้า
* **FR-6.3:** Admin สามารถยกเลิกคำสั่งซื้อที่ยังไม่เสร็จสิ้นได้ โดยต้องระบุเหตุผลการยกเลิก (รองรับการยกเลิกทุกช่องทาง ทั้ง LINE, Facebook และหน้าร้าน)
* **FR-6.4:** ระบบต้องคืนจำนวนสินค้าเข้าสต็อกโดยอัตโนมัติ และแสดง Toast Notification เมื่อยกเลิกสำเร็จ

## 4. กฎทางธุรกิจ (Business Rules)
* **BR-07 (กฎการยกเลิกคำสั่งซื้อ):** ทำได้เฉพาะรายการที่ยังไม่เสร็จสิ้น และ Admin ต้องระบุเหตุผลทุกครั้ง สต็อกจะถูกคืนกลับระบบโดยอัตโนมัติ

## 5. ข้อมูลที่เกี่ยวข้อง (Data Requirements)
* ประวัติคำสั่งซื้อ, เหตุผลการยกเลิก (Order Cancellation Log), วันที่และเวลาที่ยกเลิก

## 6. ส่วนติดต่อผู้ใช้งาน (User Interface)
* **หน้าประวัติคำสั่งซื้อ:** ตารางออเดอร์, Pop-up รายละเอียด, ปุ่มยกเลิกคำสั่งซื้อพร้อมฟอร์มระบุเหตุผล

## 7. เกณฑ์การยอมรับ (Acceptance Criteria)
* **AC-03:** เมื่อ Admin ยกเลิกคำสั่งซื้อและระบุเหตุผล ระบบต้องดำเนินการคืนสต็อกอัตโนมัติ และแสดง Toast แจ้งเตือนสำเร็จ
