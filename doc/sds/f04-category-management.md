# F-04: การจัดการหมวดหมู่ (Category Management)

## 1. คำอธิบายฟีเจอร์ (Feature Description)
ระบบสำหรับจัดกลุ่มสินค้าเข้าด้วยกัน เช่น น้ำมันเครื่อง, ยางรถจักรยานยนต์ เพื่อความสะดวกในการค้นหาและจัดการ

## 2. กลุ่มผู้ใช้งาน (Target Users)
* ผู้ดูแลระบบ (Admin)

## 3. ความต้องการทางฟังก์ชัน (Functional Requirements)
* **FR-4.1:** Admin สามารถเพิ่มหมวดหมู่สินค้าใหม่ได้
* **FR-4.2:** Admin สามารถแก้ไขชื่อหมวดหมู่สินค้าได้
* **FR-4.3:** Admin สามารถลบหมวดหมู่สินค้าออกจากระบบได้
* **FR-4.4:** ระบบรองรับการกำหนดหมวดหมู่ให้กับสินค้าในหน้าจัดการสินค้า

## 4. กฎทางธุรกิจ (Business Rules)
* **BR-04 (เงื่อนไขการลบหมวดหมู่):** หมวดหมู่สินค้าที่จะลบออกจากระบบได้ ต้องไม่มีรายการสินค้าผูกอยู่กับหมวดหมู่นั้น หากมี ระบบต้องแสดงการแจ้งเตือน

## 5. ข้อมูลที่เกี่ยวข้อง (Data Requirements)
* รหัสหมวดหมู่, ชื่อหมวดหมู่

## 6. ส่วนติดต่อผู้ใช้งาน (User Interface)
* **หน้าจัดการหมวดหมู่สินค้า:** แสดงตารางหมวดหมู่ และฟอร์มสำหรับเพิ่ม/แก้ไข/ลบหมวดหมู่
