# F-05: การจัดการคำสั่งซื้อ (Order Management)

## 1. คำอธิบายฟีเจอร์ (Feature Description)
ระบบสำหรับให้ Admin บันทึกคำสั่งซื้อที่มาจากช่องทางออนไลน์ (Facebook, LINE) รวมถึงการระบุข้อมูลลูกค้า วิธีการชำระเงิน และตัดสต็อกอัตโนมัติ

## 2. กลุ่มผู้ใช้งาน (Target Users)
* ผู้ดูแลระบบ (Admin)

## 3. ความต้องการทางฟังก์ชัน (Functional Requirements)
* **FR-5.1:** Admin สามารถเปิดบันทึกคำสั่งซื้อใหม่และเลือกช่องทาง (LINE, Facebook, หน้าร้าน)
* **FR-5.2:** Admin สามารถกรอกข้อมูลชื่อผู้รับ ที่อยู่จัดส่ง และเบอร์โทรศัพท์ (สำหรับ LINE, Facebook)
* **FR-5.3:** รองรับการเพิ่มที่อยู่จัดส่งแห่งใหม่เพิ่มเติมในข้อมูลลูกค้ารายเดิม
* **FR-5.4:** Admin สามารถเลือกสินค้าและระบุจำนวนที่สั่งซื้อ
* **FR-5.5:** เลือกวิธีการชำระเงิน (โอนเงิน, เก็บเงินปลายทาง) และสถานะการชำระเงิน
* **FR-5.6:** ระบบจะตัดสต็อกอัตโนมัติเมื่อทำการบันทึกออเดอร์สำเร็จ และย้ายคำสั่งซื้อไปหน้าประวัติ
* **FR-5.7:** แสดงข้อความแจ้งเตือน (Toast Notification) ระบุเลขที่คำสั่งซื้อเมื่อบันทึกสำเร็จ

## 4. กฎทางธุรกิจ (Business Rules)
* **BR-01:** สต็อกสินค้าจะถูกตัดก็ต่อเมื่อคำสั่งซื้อถูกบันทึกสำเร็จ
* **BR-05 (ข้อมูลลูกค้า):** หากเลือกช่องทาง LINE หรือ Facebook จะต้องกรอกข้อมูลผู้รับให้ครบถ้วน หากเลือกหน้าร้าน ระบบข้ามไปขั้นตอนเลือกสินค้าได้
* **BR-06 (การชำระเงินออนไลน์):** รองรับ "การโอนเงิน" หรือ "การเก็บเงินปลายทาง" เท่านั้น
* **BR-08 (การจัดการสต๊อก 0):** หากสินค้ามีจำนวนสต๊อกเป็น 0 ระบบจะ Disable ตัวเลือกนั้นใน Dropdown ทันที เพื่อป้องกันการสั่งซื้อสินค้าหมด
* **BR-09 (การตั้งสถานะชำระเงิน):** เมื่อเลือก "Mark as already paid" ระบบจะตั้งสถานะออเดอร์เป็น `Paid` ทันทีโดยไม่ต้องบังคับอัปโหลดสลิปโอนเงิน

## 5. ข้อมูลที่เกี่ยวข้อง (Data Requirements)
* เลขที่คำสั่งซื้อ, วันที่สั่งซื้อ, ช่องทางการสั่งซื้อ, ข้อมูลลูกค้า (ชื่อ, ที่อยู่, เบอร์โทร), รายการสินค้าและจำนวน, ราคารวม, วิธีและสถานะการชำระเงิน

## 6. ส่วนติดต่อผู้ใช้งาน (User Interface)
* **หน้าบันทึกคำสั่งซื้อ:** ตัวเลือกช่องทาง, ฟอร์มข้อมูลลูกค้า, ส่วนเลือกสินค้าและจำนวน, ตัวเลือกวิธีชำระเงิน, Toast แจ้งเตือน

## 7. เกณฑ์การยอมรับ (Acceptance Criteria)
* **AC-02:** เมื่อ Admin บันทึกออเดอร์ กรอกข้อมูลครบถ้วน เลือกวิธีชำระเงิน และกดบันทึก ระบบต้องตัดสต็อก ย้ายรายการไปหน้าประวัติ และแสดง Toast พร้อมเลขที่คำสั่งซื้อ
