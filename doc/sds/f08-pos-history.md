# F-08: ตรวจสอบประวัติการขายหน้าร้าน (POS History)

## 1. คำอธิบายฟีเจอร์ (Feature Description)
ระบบสำหรับให้ผู้ดูแลระบบตรวจสอบยอดขายและบิลการขายหน้าร้านย้อนหลัง

## 2. กลุ่มผู้ใช้งาน (Target Users)
* ผู้ดูแลระบบ (Admin)

## 3. ความต้องการทางฟังก์ชัน (Functional Requirements)
* **FR-8.1:** แสดงประวัติการขายจากระบบหน้าร้านทั้งหมด
* **FR-8.2:** Admin สามารถเปิดดูรายละเอียดการขายหน้าร้านแต่ละบิลย้อนหลังได้ (รายการสินค้า, ยอดรวม, วิธีชำระเงิน, พนักงานที่ทำรายการ)

## 4. กฎทางธุรกิจ (Business Rules)
* ประวัติการขายจะถูกบันทึกเมื่อรายการหน้าร้านจาก Counter Staff (หรือ Admin) เสร็จสมบูรณ์

## 5. ข้อมูลที่เกี่ยวข้อง (Data Requirements)
* เลขที่บิลหน้าร้าน, วันที่, พนักงานผู้ทำรายการ, สินค้าที่ขาย, ยอดรวม, วิธีชำระเงิน

## 6. ส่วนติดต่อผู้ใช้งาน (User Interface)
* **หน้าประวัติการขายหน้าร้าน:** ตารางแสดงรายการขายหน้าร้านย้อนหลัง และปุ่มสำหรับดูรายละเอียดบิล
